# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone your-repository-url
```

Navigate to the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
